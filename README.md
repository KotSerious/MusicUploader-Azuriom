# 🎵 Music Uploader плагин для Azuriom

Удобный плагин для CMS **Azuriom v1.2+**, который позволяет игрокам вашего сервера загружать собственные музыкальные треки прямо через личный кабинет. Отличное решение для интеграции с игровыми радиостанциями, голосовыми чатами (Voice Chat) или музыкальными автоматами в Minecraft.

---

## ✨ Особенности

- 🔒 **Разграничение прав:** Доступ к загрузке выдается конкретным ролям/группам (например, VIP, Premium) через админку Azuriom.
- 🎛️ **Встроенный HTML5 плеер:** Возможность прослушать загруженные треки прямо на сайте без скачивания.
- 📋 **Копирование в один клик:** Удобная кнопка мгновенного копирования прямой ссылки на аудиофайл для вставки в игру.
- 🛠️ **Панель модератора:** Дашборд в админке для просмотра и удаления музыкальных файлов.
- 🌐 **Мультиязычность:** Полная поддержка русского (`ru`) и английского (`en`) языков.

## 🚀 Установка
### Шаг 1. Загрузка файлов
Распакуйте архив с плагином в директорию вашего сайта по пути:
```bash
/var/www/azuriom/plugins/musicuploader
```
> ⚠️ **Важно:** Название папки должно быть строго в нижнем регистре: `musicuploader`.

### Шаг 2. Включение плагина и настройка БД
1. Зайдите в **Админ-панель Azuriom** ➔ **Плагины** (Plugins).
2. Найдите в списке **Music Uploader** и нажмите **Включить** (Enable).


### Шаг 3. Настройка веб-сервера (Рекомендация)
Так как музыкальные файлы обычно весят много, убедитесь, что в вашем `php.ini` выставлены достаточные лимиты:
```ini
upload_max_filesize = 64M
post_max_size = 64M
memory_limit = 256M
```
_После изменения настроек перезапустите веб-сервер (Apache/PHP-FPM)._

---

## ⚙️ Настройка прав (Permissions)

1. Перейдите в **Админ-панель** ➔ **Пользователи** ➔ **Роли**.
2. Отредактируйте группу, которой хотите дать доступ к музыке.
3. Поставьте галочку напротив разрешения: `Загрузка музыки`.
